Adaptive Physiological State Model
Every patient enters the programme with a different physiological state. Rather than treating this as a fixed diagnosis, Orcasho maintains a continuously updated model of it.
Its purpose is not to declare biological truth — it is to generate the next adaptive intervention, then evaluate whether that intervention was consistent with what actually happened next.

How is the model constructed?
Adaptive Physiological State Model
Every patient is represented by a continuously evolving physiological state rather than a fixed diagnosis.
The model integrates multiple biochemical and clinical dimensions into a single adaptive representation of the patient’s current physiology.
Every twenty days, new longitudinal observations update that representation.
The next intervention is then selected based on the patient’s current physiological state, not the state observed weeks earlier. This process repeats continuously throughout care.
Technical implementation

Internally, the model represents each patient using a multi-dimensional biochemical state space that incorporates our working hypothesis around digestive physiology, biochemical interactions, and ionic equilibrium. This representation is continuously updated as longitudinal observations accumulate.
