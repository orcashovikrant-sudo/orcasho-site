▼ About this table
Rows in plain text are inputs (edit them directly, changes save automatically). Rows in bold (Gross Sales, Net Sales, Gross Income, NM, Contribution Margin, EBITDA, PBT, Net Income) and the percentage rows are calculated from the inputs above them, matching the formulas in the original workbook, so you never edit those directly.

Data lives in the Firestore collection mis_rows, one document per input line, in the same Firebase project as before. The original sheet also carried three reconciliation cells that did not line up under any row label: an entry marked "Fine" worth ₹2,36,222.45, a follow-on calculation of −₹6,718.63, and a second, valueless "Fine" label. Those are historical artifacts of the workbook rather than part of its row structure, so they are noted here rather than built into the live table.

Firestore access. If the sync dot above stays grey or red, edits aren't being saved. Go to the Firebase console for this project → Firestore Database, and make sure the Rules tab allows reads and writes, for example:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
